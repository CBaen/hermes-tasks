## What it does

Coordinates the next-stage capability process for Moji: multi-root routing, evidence-gated evolution, synthesis loops, terminology support, project/document cleanup, per-agent capability growth, and Guiding Light's operating-manual layer.

## When to reach for it

Use when Guiding Light asks Moji to improve its own operating system, continue
capability framework adoption, synthesize Claude/Codex/peer-agent patterns, or turn
recurring support needs into reusable processes.

## How to use it

Treat the following as connected workstreams, not isolated chores:

1. **Multi-root routing** - use visible project roots, scoped roots, and adapter roots together.
2. **Claude-folder synthesis** - review `.claude` safely and translate only reusable lessons into Codex/shared memory, capabilities, tools, or project guidance.
3. **Learning loop / Qdrant path** - keep dry-run/report-first until reviewed exports are ready for vector writes.
4. **Terminology coach** - capture repeated vocabulary mismatches and teach the correct terms in context.
5. **Git/documentation story synthesis** - read commits, docs, and diffs as narrative evidence, not just file changes.
6. **Stale-file cleanup** - identify stale docs/files with evidence before archiving or deleting.
7. **Per-agent evolving capabilities** - let Moji, Codex, Claude-derived patterns, named agents, and project agents each have their own capability surfaces.
8. **Guiding Light Operating Manual layer** - synthesize durable collaboration rules, not raw private conversation.
9. **Reliable agent orchestration** - prefer named narrow lanes with output files over broad swarms.

Use foundation cards for early process definitions. Upgrade only when a loop has repeated successful use and evidence.

## Failure modes

- Treating all future systems as one monolith.
- Automating raw/private ingestion before review and redaction.
- Promoting rough ideas to verified/staple because they sound right.
- Creating many agents without clear root ownership, output paths, and synthesis gates.
- Making Guiding Light manage the machinery instead of letting the machinery conserve their attention.

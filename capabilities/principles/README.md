# Principles

Use this folder for reusable rules and constraints that shape many capabilities.

A principle is not a procedure and not a single tool. It is a guardrail that tells future agents what must stay true while they combine ingredients and recipes.

Formal principle cards use the same schema as other capabilities:

```yaml
---
name: Human-readable name
schema_version: 1.1
level: principle
last_verified: YYYY-MM-DD
---
```

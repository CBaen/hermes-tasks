## What it does

Captures ideas, tangents, and future tasks with almost no ceremony so they are not lost and do not derail the current critical path.

Adapted from Claude GSD's `gsd-note` pattern.

## When to reach for it

Use when GL or Moji surfaces an idea that is useful but not the right active lane.

Good fits:

- “remember this idea”;
- tangent during deep work;
- possible future feature;
- question to investigate later;
- terminology/glossary candidate;
- project seed.

## How to use it

1. Capture the note immediately in the nearest relevant queue/backlog/notes file.
2. Do not ask formatting questions.
3. Include timestamp/date, source context, and project/workstream if known.
4. Return to active work unless the note changes priority.
5. Later, promote notes into structured todos/capabilities/projects only when needed.

Suggested destinations:

- project queue/status file;
- nearest active memory/capability inbox for reusable lessons;
- project glossary or vocabulary file for terminology;
- project cleanup queue for stale-file candidates;
- `research/<topic>/PAUSED-NOTES.md` for parked migration thoughts.

## Failure modes

- Turning capture into a planning session.
- Losing the note in chat instead of a file.
- Letting a captured tangent silently become the active task.
- Over-structuring notes before they prove value.

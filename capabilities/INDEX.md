# Hermes Tasks Capabilities

This index routes agents to reusable project knowledge. The full capability
framework should be present as reference material, but foundation is the
default profile for actual use.

This root is part of the project capability graph. It can link to other roots in
this project, other projects, agent-specific folders, feature/domain roots, or a
subject/person capability root when that helps agents do the work correctly.

## Root Label

- Purpose: Reusable project operating knowledge, verification patterns, workflows, and references for this repo.
- Belongs here: Project-specific capability cards, process notes, contracts, reusable verification steps, and linked supporting knowledge.
- Does not belong here: Secrets, auth/session files, raw logs, runtime caches, or one-off scratch notes better kept in queue/handoff/workstream docs.
- Related roots: `/home/guidingl/capabilities` (systemwide shared root); `/home/guidingl/.hermes/profiles/banebook/capabilities` (Banebook Hermes purpose root).

## How to use this

1. Start with the project `AGENTS.md`.
2. Skim this index before substantial project work.
3. Open only the specific capability files needed.
4. Use foundation cards for simple routing, contracts, dependencies, kitchen
   notes, and "what this helps with."
5. Upgrade to governed, composition, or cascade tracking only when evidence,
   risk, repeated use, or dependency impact earns it.
6. Keep this index hub/spoke. Link to files and folder spokes; do not turn this
   file into the whole manual.
7. Cross-link and backlink to related roots when capabilities compose across
   project, agent, feature, domain, subsystem, or subject boundaries.
8. Meals live with the consuming capability root that references and uses the
   ingredient chain.
9. Broken dependency chains go on watch or probation. Greenlit trust returns
   only after three evidence-backed successful uses.
10. Do not mutate trust-bearing fields casually. Changes to maturity,
   `currently_true`, confidence, promotion state, or watch status need
   evidence, date, result, confidence, and rollback or revalidation.
